## Coverage gaps

- Native local platform: Windows, Python 3.13.15. Local Linux NOT RUN. Static
  win32 mypy is separate from execution evidence; the default mypy run also ran on Windows.
- Full local run: 951 passed and 5 skips. Four Windows symlink cases need a
  privilege unavailable locally; one test is POSIX-only. Unchanged Windows CI
  requires the four symlink cases to execute, and native Windows/Linux CI is pending.
- Parent execution passes all 173 cases. Initial independent execution passed
  169 cases and 229 reviewer-authored probes; later review found and verified the
  focused R1 root-classification correction. Refreshed independent execution
  passes 173 dedicated cases and 229 probes at the fixed code SHA. Fixed-document
  review is recorded separately; local evidence does not self-approve WP-14.
- Guards cover scoped module initialization after dependency loading and calls
  after fixture construction. They do not claim all dependencies are inert.
- Mutation evidence changes functions/constructor seams only in isolated
  processes; no tracked product mutation survives. Original log hashes identify
  the preserved files outside Git; any excerpt or node index is explicitly derived.
- Scale measurements are observations, not new limits. Parser/interpreter limits
  and inherited hash expansion costs remain; no byte-integrity/authentication,
  durable history, atomic commit, membership/rollover recovery or real Excel
  behavior is established by this package.
