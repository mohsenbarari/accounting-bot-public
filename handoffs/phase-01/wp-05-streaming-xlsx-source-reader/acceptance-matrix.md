## Coverage gaps

This handoff delivery covers the limited R5-B remediation based on findings RB-01 through RB-05:
- **RB-01 (Pass 1 inlineStr container extraction):** Pass `&lt;is&gt;` element to `_extract_text_from_si_or_is` during activity discovery, supporting plain text, rich runs (`&lt;r&gt;&lt;t&gt;`), comments/tails, and Persian/ASCII zeros across all 4 sheets and namespaces.
- **RB-02 (Escape & whitespace unification):** Unified OOXML escape decoding (`_decode_ooxml_escapes`) and whitespace semantics between discovery and decode so escaped whitespace (`_x0020_`, `_x0009_`, `_x000D_`, `_x00A0_`) is inactive, while double escapes (`_x005F_x0020_`) and escaped NUL (`_x0000_`) remain active.
- **RB-03 (Lazy secondary SST evaluation & consumer coordinates):** Secondary SST cells (`record_id`, `date_raw`) are only validated and decoded if row activity is confirmed; inactive rows with 5000-digit string indices are safely skipped; exact consumer coordinates (`sheet_name`, `cell_ref`, `physical_row_number`) are attached to needed SST decode failures and surrogate errors.
- **RB-04 (Regression suite completion):** Added 30 comprehensive regression tests in `tests/test_xlsx_source_reader_sst_activity_regressions.py` asserting full snapshot equality, WP-03 source hashes, Decimal scale preservation with `as_tuple()`, equivalent representation/permutation invariance, and stream pass bounds for N=1 and N=200.
- **RB-05 (Documentation integrity):** Restored approved performance criterion (< 15.0s, < 128 MiB) under XR-12; documented historical RED baseline and exact command outputs in `test-results.txt`.

Findings R5-04, R5-05, and R5-06 remain OPEN / PENDING subsequent review rounds within WP-05. Execution on Windows is PENDING independent Codex Windows CI.
